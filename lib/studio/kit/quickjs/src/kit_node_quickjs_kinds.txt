# The kinds of Studio Kit's QuickJS binding that tools/gen/gen_kit.py describes from the kit's headers, and what the
# headers cannot say of them. Run `./dev.sh gen kit` after changing this file or a header of the kit, which writes
# kit_node_quickjs_kinds.cpp. The first comment of that file is the reference of these kinds for a script's author.
#
# A line that is not indented begins a kind: the name of its element, and the kit's function that creates its widget.
# The function takes the kit, the parent and, for most, a content and a style. Every field of what it takes after the
# parent is an attribute of the kind, named as the field is with a hyphen between its words, and read in the form that
# the field's type gives. A struct of the kit's that a struct holds gives its fields as the struct's own. A float is a
# length, which is zero or more, in a struct named as a style, and any number elsewhere. Three fields are not
# attributes: the content's key, which is the node's, a style's place, which is the node's placement, and padding.
#
# The lines indented under a kind say the rest:
#
#   text <field>                The string that shows the node's text, which is then no attribute.
#   attribute <name> <field>    An attribute whose name is not its field's.
#   omit <field>                A field that the kind leaves zero, and that is no attribute.
#   number <field>              A float that is any number where the rule above makes it a length.
#   length <field>              A float that is a length where the rule above makes it any number.
#   under <kind>                The kind that a node's parent must be of for the node to be declared.
#   leaf                        The widget holds nothing, so the nodes under the kind's node are not declared.
#   event <type> <query>        An event that the kind queues, with no detail, in each round in which the kit's query,
#                               a function of the kit and the widget's node, holds for the widget.
#
# The generator fails on a field whose type has no attribute form. A kind that needs more than these lines say is
# written by hand, in the source of its family: one whose widget reads or writes through a pointer, whose event
# carries a detail, or that declares the nodes under it itself.
