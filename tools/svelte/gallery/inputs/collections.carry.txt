# The example's three views are one scroll container, so each shows where the view before it was scrolled to. The
# section's list and tree are two nodes of one key, which makes them one widget.

# The tree shows where the list was scrolled to.
scroll 500 400 0 500
settle
click 141 226
settle
screenshot tree

# The list shows where the tree was then scrolled to, and so does the grid after it, whose rows are taller.
scroll 500 400 0 -200
settle
screenshot tree-back
click 56 226
settle
screenshot list
click 99 226
settle
screenshot grid

# The tree is shorter than where the grid is scrolled to, so it shows its end. The offset stands meanwhile, and the
# list after the tree shows where the grid was.

settle

click 141 226
settle
screenshot tree-end
click 56 226
settle
screenshot list-far
